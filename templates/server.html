AmneziaWG properties

These values are added to generated server and client configs. On Keenetic clients, Jc, Jmin, and Jmax may be changed manually; all other AmneziaWG values must match the generated client config.

AmneziaWG 3.1, shared

HeaderProtectionKey is a shared secret: both ends run the same keystream over the start of every packet, so a client without it cannot classify incoming packets. It is written into generated client configs, so hand it out like a private key. It requires S1 to S4 to be at least 12.

AmneziaWG 3.1, server only

DisableCookies only suppresses sending cookie replies, which is something the responder does, so these are not written into client configs.

AmneziaWG 3.1, client only

Each value is a single number or a lo-hi range in 0..65535. These are written into generated client configs only.
